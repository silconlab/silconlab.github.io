# 주식회사 실컨 (SILCONLAB) 공식 웹사이트

실행 중심 경영컨설팅 전문기업 (주)실컨의 공식 랜딩페이지 및 고객 상담 접수 시스템입니다.

## 주요 기능
- **동적 히어로 슬라이더 & 반응형 네비게이션**
- **실컨 4대 솔루션 & 투명한 가격 정책 안내**
- **업종별 고객 성공 사례 탭 필터링**
- **대표 총괄 컨설턴트 약력 및 차별화 원칙 소개**
- **비동기 1:1 상담 신청 & 실시간 유효성 검증 폼**
  - 성함/연락처/이메일 오입력 방지 및 자동 하이픈
  - 1차 신청내용 수정 및 2차 추가문의 독립 관리 (듀얼 카드)
  - Google 스프레드시트 CRM 실시간 자동 적재 및 이메일 알림 연동

## 디렉토리 구조
```
├── index.html                  # 메인 랜딩페이지
├── css/
│   └── style.css               # 공식 스타일시트
├── js/
│   └── main.js                 # 상호작용 및 폼 유효성/연동 스크립트
└── .github/
    └── workflows/
        └── deploy.yml          # GitHub Pages 자동 배포 워크플로우
```

## GitHub Pages 배포 방법
1. 본 저장소의 코드를 GitHub의 `main` 브랜치에 푸시합니다.
2. 저장소의 **Settings** > **Pages**로 이동합니다.
3. **Build and deployment** > **Source**를 `GitHub Actions`로 설정합니다.
4. 푸시될 때마다 `.github/workflows/deploy.yml`이 자동 실행되어 즉시 웹에 배포됩니다.
